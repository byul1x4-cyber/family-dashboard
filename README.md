# 🏡 우리집 다모아

아이 루틴 체크부터 칭찬하기, 가족 일정, 우체통, 식판·약·성장 기록까지 한 화면에 모은 우리집 가족 대시보드입니다.
민국·이준을 **나란히** 두고 전환 없이 한 화면에서 누를 수 있게 구성했습니다.
설치도 빌드도 필요 없는 순수 정적 웹앱이라, 링크만 열면 바로 쓸 수 있습니다.

- 앱 주소: **https://byul1x4-cyber.github.io/family-dashboard/**
- 사용 환경: 아이패드/태블릿(거실 상비), 휴대폰, 데스크톱 모두 반응형

## 기능

| 탭 | 내용 |
| --- | --- |
| 🏠 홈 | 오늘 날씨·미세먼지와 옷차림 한 줄, **엄마·아빠 지금 상태 칩**(프리셋 7개 + ✏️ **직접 적기** — 적은 문구·이모지 그대로 가족 기기에 표시), 민국·이준 큰 카드(⭐·키·몸무게·오늘 남은 일), 파스텔 타일 4개(할 일/우체통/골고루 먹자/이만큼 자랐어요), 이번 달 미니 달력 + D-day 일정, 민국이 알림장, 약 먹고 있는 사람, 🛒 장보기. |
| ✅ 할 일 | 민국(왼쪽)·이준(오른쪽) 루틴을 **한 화면에 나란히**. 상단에서 전체/아침/저녁만 고르고, 각 아이 카드에서 바로 “다 했어요!”를 누르면 **곱셈 문제 없이 즉시 완료**되고 별 ⭐ 1개가 쌓입니다. 아침 할 일은 **⏰ 스스로 일어나기 · 세수·양치하기 · 옷 갈아입기 · 아침밥 먹기 · 가방·물통 챙기기(5개)** 이고, **아이 모드에서는 등교 시각(기본 08:30)이 지나면 아침 별 체크가 잠깁니다**(🔒 08:30 마감 · 부모님 모드는 언제든 체크·해제). 부모님 모드에서는 카드 아래 **＋ 할 일 추가**(누구에게·아침/저녁·아이콘·제목)와 항목마다 **🗑️**로 목록을 직접 고칩니다. |
| ⚡ 포켓몬 | 별을 먹여 **알 → 1단계 → 2단계 → 3단계(최종 진화)** 로 키웁니다. 3단계 진화 라인 **20가지**(피츄·파이리·꼬부기·이상해씨·냐오하·뜨아거·꾸왁스·개구마르·미뇽·고오스·토게피·랄토스·아차모·물짱이·나무지기·팽도리·치코리타·브케인·리아코·애버라스), 기본 **별 100개마다 한 단계 진화**(부모님 모드에서 조절). 부화·진화 순간 빛 플래시·꽃가루·축하 팝업·효과음이 나고, 최종 진화하면 반짝이는 **도감**에 등록돼 새 알을 받을 수 있어요.<br>🥚 **알 단계에서는 정체를 완전히 숨깁니다** — 화면에는 알과 "무슨 포켓몬이 나올까?"만 보이고, 알을 받는 순간 20라인 중 **아직 도감에 없는 포켓몬이 랜덤**으로 정해져 부화할 때 공개돼요. 아직 도달하지 않은 다음 진화 모습과 도감의 미수집 포켓몬도 **까만 흑백 실루엣 + ???** 로만 보입니다(부모님 모드는 설정 → 포켓몬 관리에서 실제 알 확인·🎲 알 다시 뽑기·초기화). 화면 맨 위 칩으로 **민국 / 이준**을 고르면 그 아이의 알 카드와 **바로 아래 "○○의 포켓몬 도감"**(그 아이가 모은 것만)이 한 줄로 이어져 보입니다 — 패드·데스크톱에서도 나란히 두지 않고 세로로 쌓여 한눈에 들어옵니다. |
| 🌟 칭찬하기 | 왼쪽 민국·오른쪽 이준 칭찬 버튼을 나란히 두고 전환 없이 칭찬 적립(별 ⭐·칭찬 횟수)과 최근 기록을 봅니다. **부모님 모드**에서는 최근 기록 줄 오른쪽 **취소** 버튼으로 잘못 누른 칭찬을 되돌립니다(기록 삭제 · 칭찬 횟수 1 감소 · 그때 준 별 1개 차감, 보유 별이 없으면 포켓몬에게 먹인 별에서 빠짐). 아이 모드에는 취소 버튼이 없습니다. |
| 📅 우리 가족 일정 | 월간 달력 + 다가오는 일정. 부모님 모드의 **＋ 일정·준비물**로 날짜·제목·종류(가족/학교/학원/준비물/기타)·**준비물 목록**을 함께 넣고, 다가오는 일정에서 **🎒 준비물 칩**을 눌러 하나씩 챙김 체크합니다. |
| 📮 우체통 | 민국·이준이 엄마·아빠에게 **손글씨 편지**(캔버스에 손가락·펜으로 쓰기, 색·굵기·지우개·처음부터)와 그림(픽토그램)·짧은 글을 보냅니다. 대화는 **전체 가족방**(엄마·아빠·민국·이준이 한 방에서 시간순, `민국 → 엄마`처럼 방향·프로필 표시)이고, **[전체 가족방] / [민국] / [이준]** 칩으로 각자 대화만 골라 볼 수 있습니다. 아이 편지 말풍선 아래 **빠른 답장 6개**(사랑해❤️·알았어👍·곧 갈게🚗·잘했어👏·전화할게📞·안 돼🙅)를 바로 누르고, 아래 고정 답장창에서 직접 입력도 합니다. 🎤 눌러서 말하기(한국어 음성 인식), 편지 소리 내어 읽기. (그림 개수·보내는 횟수 제한 없음) |
| 🍱 식판·건강 | 오늘 식판(밥·국·반찬 3) 메뉴는 **두 아이 공통**으로 고르고, 먹은 정도(안 먹음/1번/적당히/전부)는 **민국·이준 카드를 나란히** 두고 각각 누릅니다. 식판 아래 **⭐ 퀵메뉴**에 자주 내는 반찬·메뉴(이름·아이콘·보통 그릇·재료)를 부모님 모드에서 **등록·추가·🗑 삭제**하고, 칩을 한 번 누르면 **오늘 식판 그릇에 바로** 들어갑니다(보통 그릇에 다른 음식이 있으면 그릇을 골라 넣음). **＋ 오늘만 넣기**는 저장 없이 오늘 식판에만 올리고, **＋ 퀵메뉴 등록**은 저장해 다음에도 다시 씁니다. 등록한 메뉴는 가족 클라우드에 저장돼 아이·부모 기기에 함께 보입니다. 재료 통계, 약 복용 체크, 키·몸무게 기록과 성장 그래프. |
| 🏫 민국이 알림장 (홈) | 엄마가 확인한 언주초 1학년 3반 알림장(준비물·숙제·하교 안내)을 민국이 눈높이 문장으로 홈 화면에 크게 보여 줍니다. 부모님 모드의 **알림장 고치기**로 제목·날짜·한 줄 응원·항목을 적고, 챙긴 항목은 민국이가 직접 눌러 체크합니다. 등록 전에는 “아직 등록된 알림장이 없어요”로 비어 있습니다. |
| ⏰ 그만! 알림 | 헤더의 ⏰ 버튼으로 5/10/15/30분 뒤 또는 끝내는 시간을 정하면 남은 시간이 헤더에 표시되고, 시간이 되면 전체 화면 알림 + “이제 그만 볼 시간이에요! 화면을 꺼 주세요.”를 소리 내어 읽어 줍니다. (이 기기에만 저장) |
| 📢 태블릿에 한마디 | 부모님 모드에서 한 줄 적고 **[띄우기]**를 누르면 거실 태블릿 화면 가운데에 **큰 “빵!” 팝업**(`💌 엄마가 보낸 메시지` + **[확인했어요]**)이 뜹니다. **[내리기]**로 바로 내릴 수 있고, 아이가 확인을 누르면 `ackedBy`에 기록돼 부모님 화면에 **읽음 ○명**으로 보입니다. (홈 카드 · 우체통 · 헤더 📢 버튼) |
| 🔔 새 메시지 알림 | 새 편지·답장이 실시간으로 도착하면 화면 오른쪽 아래에 **새 메시지 배너 팝업**이 뜨고, 설정에서 **알림 소리 · 소리 내어 읽기 · 브라우저 알림(권한 허용)**을 켜고 끌 수 있습니다. |
| 🛒 장보기 | 홈에서 누구나 필요한 품목을 적어 넣고, 산 물건은 동그라미를 눌러 완료(취소선)합니다. ✕로 지우고, 태블릿·폰에 실시간으로 함께 보입니다. |
| 🌤 오늘 날씨 | 홈 맨 위에 기온·날씨·미세먼지와 한 줄 옷차림 팁(우산·겉옷·마스크). Open-Meteo 무료 API를 쓰며(키 없음), 15분 캐시하고 실패하면 조용히 넘어갑니다. |
| ⚙️ 설정 | **부모님 모드에서만 보이는 탭**입니다(아이 모드에는 탭 자체가 숨고, 설정 화면에 있다가 아이 모드로 바꾸면 홈으로 돌아갑니다). 가족 입장 코드 변경, 이 기기 잠금, 저장 방식·연결 상태, 데이터 내보내기·가져오기·초기화. |
| 📲 폰·패드 잠금화면 알림 | 설정 탭에서 켜고 끄는 **ntfy 기반 잠금화면 푸시**. 가족방 새 편지·답장, 📢 태블릿 한마디, 테스트 알림이 엄마 아이폰·아이들 갤럭시 패드의 잠금화면에 뜹니다. 앱을 꺼 두어도 옵니다. |
## 모드

- **아이 모드**: 아이가 직접 루틴을 체크하고 편지를 씁니다. 칭찬·일정·식판·성장 기록은 잠겨 있고, **⚙️ 설정 탭은 보이지 않습니다**. 홈의 아이 카드나 각 탭의 아이 버튼으로 **민국 ↔ 이준**을 자유롭게 바꿀 수 있고, 어느 화면에서 바꾸든 모든 탭이 같은 아이를 봅니다.
- **부모님 모드**: 아이 모드에서 바꿀 때는 매번 새로 나오는 **곱셈 문제(부모님 확인 문제)**를 맞혀야 열립니다. 정답을 맞히면 엄마/아빠를 고르고, 완료 되돌리기·칭찬·일정 추가/삭제·식판·약·성장 기록을 관리합니다. 부모님 → 아이 모드는 문제 없이 바로 바뀝니다.

## 가족 입장 코드 (잠금)

이 저장소는 공개되어 있지만, 앱을 열면 먼저 **가족 입장 코드**를 물어봅니다.

- 코드는 4자 이상(숫자·단어 무엇이든)이며, 띄어쓰기와 영문 대소문자는 구분하지 않습니다.
- 입력한 코드는 앱 코드에 저장되지 않습니다. 브라우저에서 `SHA-256`으로 해시한 값의 앞 24자리만 Firestore 문서 ID로 씁니다.
  - 문서 경로: `families/fam_<해시 24자리>` (예: `fam_9f2c…`)
  - 코드를 모르면 문서 ID를 계산할 수 없고, 문서를 직접 지정해 읽을 수도 없습니다.
- 한 번 넣은 기기는 그 열쇠를 기억해 다음부터는 바로 들어갑니다 (`localStorage`).
- 설정 탭에서 **가족 입장 코드 변경**(기존 기록을 그대로 옮길지 선택)과 **이 기기 잠그기(로그아웃)** 를 할 수 있습니다. 기기를 잠그면 그 기기에서 열쇠와 저장된 기록이 지워집니다.
- 설정 탭에서 **전체 ID 복사**로 가족 열쇠 ID(`fam_…` 28자리)를 복사할 수 있습니다. 자동 복사가 안 되는 브라우저에서는 전체 ID 상자가 나타나 길게 눌러 복사하면 됩니다.

> ⚠️ 코드는 가족끼리만 공유하세요. 코드를 아는 사람은 그 가족 데이터를 읽고 쓸 수 있습니다.

## 저장 방식 (Firebase 실시간 동기화)

Firebase 웹 앱 설정은 `js/storage.js`의 `DEFAULT_FIREBASE_CONFIG`에 기본으로 들어 있어, 코드를 넣고 들어가면 자동으로 Firestore에 연결됩니다.
태블릿·엄마 폰·아빠 폰이 같은 코드로 들어오면 `onSnapshot`으로 몇 초 안에 서로 반영됩니다. 인터넷이 끊기면 이 기기에 먼저 저장했다가 다시 연결되면 올려 보냅니다.

### Firestore 보안 규칙 (권장)

문서 ID를 알아도 **목록 조회(list)는 막고, 문서 하나만 지정해 읽는 get만 허용**해야 외부인이 가족 문서를 훑어볼 수 없습니다.

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /families/{docId} {
      allow get: if true;              // 문서 경로를 아는 사람만 (경로 = 입장 코드의 해시)
      allow list: if false;            // 컬렉션 훑어보기 금지
      allow create, update: if true;
      allow delete: if false;
    }
  }
}
```

테스트 모드 기본 규칙(`allow read, write: if true`)은 30일 뒤 만료되고 **list까지 열려 있어** 가족 문서가 노출될 수 있으니 위 규칙으로 바꿔 두세요.

## 🔄 업데이트는 저절로 (캐시 우회)

사파리·홈 화면 아이콘은 예전 화면을 캐시에 오래 남겨서, 새 코드를 올려도 한참 뒤에야 보이는 일이 있었습니다. 그래서 앱이 스스로 버전을 확인합니다.

- `index.html`의 `<head>`에 캐시 방지 메타 태그(`Cache-Control: no-cache, no-store, must-revalidate`, `Pragma: no-cache`, `Expires: 0`).
- `js/app.js`의 **`APP_ASSET_VERSION`** = 지금 실행 중인 버전(현재 `36`).
- 앱이 열릴 때·다시 앞으로 나올 때 `./index.html?t=<시각>`을 `cache: no-store`로 받아 HTML 안의 `app.js?v=<숫자>`를 읽고, 서버 버전이 더 높으면 `?v=<최신>`으로 `location.replace` 해 새 코드를 불러옵니다.
- 두 번 새로고침하지 않도록 `sessionStorage`에 마지막으로 옮겨 간 버전을 적어 두고, 확인은 60초에 한 번만 합니다. 오프라인이거나 요청이 실패하면 아무 것도 하지 않습니다.

> **버전을 올릴 때**: `index.html`의 모든 `?v=` 와 `js/app.js`의 `APP_ASSET_VERSION`을 **같은 숫자로 함께** 올려 주세요. 둘이 다르면 새로고침이 반복되거나 업데이트를 알아채지 못합니다.


## 📲 폰·패드 잠금화면 알림 (ntfy)

앱을 꺼 두어도 폰·패드 **잠금화면**에 가족 소식이 뜨도록 [ntfy](https://ntfy.sh) 공개 푸시 서비스를 씁니다. 서버를 따로 두지 않습니다.

- **우리 가족 전용 토픽**: 가족 열쇠 ID(`fam_…`)를 `SHA-256`으로 해시한 앞 16자리 → `woori-damoa-<16자리 hex>`
  (예: `fam_e4f076e2b66030eaf37fb286` → `woori-damoa-860792dfea1ce9d9`)
  같은 가족 코드를 넣은 기기는 저절로 같은 토픽을 알게 되고, 코드를 모르면 토픽을 추측할 수 없습니다.
- **보내는 때**: ① 우체통 가족방에 새 편지·답장이 저장될 때 ② 📢 태블릿에 한마디 **[띄우기]** ③ 설정의 **[🔔 테스트 알림 보내기]**
- **보내는 방법**: `POST https://ntfy.sh/` 에 JSON 본문(`topic`·`title`·`message`·`click`·`priority`)으로 보냅니다.
  HTTP 헤더(`Title:`)에 한글을 넣으면 브라우저가 `ISO-8859-1` 오류를 내므로 JSON 방식만 씁니다.
- **실패해도 저장은 그대로**: 발송은 비동기 `try/catch`로 분리해, ntfy가 막혀도 Firestore 저장·화면은 정상입니다.
- **폰에서 받기(한 번만)**: 아이폰 앱스토어 / 갤럭시 패드 플레이스토어에서 `ntfy` 설치 → 앱에서 `+` → `Subscribe to topic`에 설정 탭의 주소를 붙여넣기 → 알림 허용.
- 토픽을 아는 사람은 그 알림을 받을 수 있으니 **가족 밖에는 알려 주지 마세요**. (알림 본문에는 편지·한마디 내용이 담깁니다.)

공개 저장소입니다. 앱에는 **가족 표시 이름과 아이 키·몸무게 기록만** 들어 있습니다.
집 주소, 전화번호, 이메일, 생년월일 같은 정보는 코드에 넣지 않았습니다. 날씨는 **동네 수준의 좌표(도곡동 일대)만** Open-Meteo에 묻고 그 밖의 정보는 보내지 않습니다. 기록은 각 기기(또는 가족 Firebase)에만 저장되고 이 저장소에는 올라가지 않습니다.
가족 입장 코드 자체도 저장소에 올라가지 않습니다(해시 값만 브라우저에서 계산).

## 라이선스

가족 사용을 위한 개인 프로젝트입니다.
