# 🏡 우리집 다모아

아이 루틴 체크부터 칭찬·돼지저금통, 가족 일정, 우체통, 식판·약·성장 기록까지 한 화면에 모은 우리집 가족 대시보드입니다.
설치도 빌드도 필요 없는 순수 정적 웹앱이라, 링크만 열면 바로 쓸 수 있습니다.

- 앱 주소: **https://byul1x4-cyber.github.io/family-dashboard/**
- 사용 환경: 아이패드/태블릿(거실 상비), 휴대폰, 데스크톱 모두 반응형

## 기능

| 탭 | 내용 |
| --- | --- |
| ✅ 할 일 | 민국·이준의 아침/저녁 루틴 체크. “다 했어요!”를 누르면 **부모님 확인 곱셈 문제**가 나오고, 맞혀야 완료됩니다. 완료할 때마다 별 ⭐ 1개. |
| 🐷 칭찬·저금통 | 칭찬 항목을 눌러 별·칭찬 횟수 적립. 돼지저금통은 `+100원 / +500원 / -100원 / 현금 줬어요`와 최근 기록. |
| 📅 우리 가족 일정 | 월간 달력 + 다가오는 일정. 누구 일정인지 색 태그로 구분하고 추가·삭제할 수 있습니다. |
| 📮 우체통 | 민국·이준이 엄마·아빠·할머니·할아버지에게 그림(픽토그램) 2개 + 짧은 글을 보냅니다. 부모·조부모는 빠른 답장이나 글로 답장하고, 편지를 소리 내어 읽어 줄 수 있어요. (한 시간에 3통까지) |
| 🍱 식판·건강 | 오늘 식판(밥·국·반찬 3)의 먹은 정도(안 먹음/1번/적당히/전부)와 재료 통계, 약 복용 체크, 키·몸무게 기록과 성장 그래프. |
| ⚙️ 설정 | 저장 방식 안내, Firebase 연결, 데이터 내보내기·가져오기·초기화. |

## 모드

- **아이 모드**: 아이가 직접 루틴을 체크하고 편지를 씁니다. 칭찬·저금통·일정·식판·성장 기록은 잠겨 있습니다.
- **부모님 모드**: 엄마/아빠를 고르면 관리 기능이 열립니다. 완료 되돌리기, 칭찬, 저금통, 일정 추가/삭제, 식판·약·성장 기록을 관리합니다.

## 저장 방식

1. **기본 — 이 기기(localStorage)**: 설치 없이 바로 동작합니다.
2. **Firebase 실시간 동기화(선택)**: 설정 탭에 Firebase 웹 앱 설정값(`apiKey`, `authDomain`, `projectId`, `appId`)을 넣고 `연결하기`를 누르면 Firestore 문서 하나(`families/our-family`)에 저장되어 여러 기기가 같은 데이터를 실시간으로 함께 씁니다.
   - Firestore 보안 규칙 예시:
     ```
     match /families/{doc} { allow read, write: if true; }
     ```

## 파일 구성

```
index.html          화면 뼈대
css/styles.css      파스텔 카드 UI (반응형)
js/data.js          가족·루틴·음식·픽토그램 등 설정값
js/storage.js       저장소 어댑터 (localStorage ⇄ Firestore)
js/ui.js            토스트·모달·차트 등 공용 UI
js/app.js           화면 렌더링과 동작
```

## 개인정보

공개 저장소입니다. 앱에는 **가족 표시 이름과 아이 키·몸무게 기록만** 들어 있습니다.
집 주소, 전화번호, 이메일, 생년월일 같은 정보는 코드에 넣지 않았습니다. 데이터는 각 기기(또는 연결한 본인 Firebase)에만 저장되고 이 저장소에는 올라가지 않습니다.
